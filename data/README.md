# Sample workout data

This folder contains example datasets for testing the GymStats dashboard.

Files:
- `sample-workouts.json` - structured GymKing-style export used by the app parser
- `sample-workouts.csv` - flat CSV version for upload testing

To test locally:
1. Open the dashboard in the browser.
2. Click the upload icon or paste data.
3. Load either JSON or CSV from this folder.

The sample data is intentionally small but varied enough to exercise:
- recovery scoring
- weekly distribution
- muscle priority cards
- the body map shading
